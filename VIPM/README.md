# CIF XNET CAN RW

LabVIEW class that reads and writes CAN frames with NI-XNET.

## Installation

1. Install `CIF_Foundation_lib_CIF_CAN_RW_Core` 1.3.0.1 or later.
2. Open **VI Package Manager (VIPM)**.
3. Install `CIF_Foundation_lib_XNET_CAN_RW` from your VIPM feed or local `.vip` file.
4. Accept the Apache License 2.0 agreement when prompted.
5. Restart LabVIEW if VIPM requests it.

Requires LabVIEW 2021 (64-bit) or later and NI-XNET.

## Palette Location

After installation, VIs are available on the LabVIEW palette at:

`Functions » Addons » CIF » CAN Read Write » XNET_CAN_RW`
